# op-brain

Brain trait and backends: codex, claude, anthropic, openai, compatible, hosted, heuristic. Owns `GET /api/brains`, `POST /api/brains/{id}/test`, the hosted brain keys (`/api/brains/hosted/keys`) and `POST /v1/decide`, which lets this server decide for other openpasture servers. API in `docs/API.md` (Decisions and brains).
